Stage 1 of 7 Foundations

🔌 Enterprise Networking Plumbing

Before servers or virtual machines can work, the network pipes must flow. 80% of student lab errors are networking faults.

🌐 1.1 IP Address, Subnet Mask & Default Gateway
▼
🏠 Real-World Analogy:
• IP Address (e.g., 192.168.1.15): Your house's unique street number.
• Subnet Mask (e.g., 255.255.255.0 or /24): Defines the neighborhood limits. All houses sharing 192.168.1.X are on your street; you can walk over and talk without leaving the neighborhood.
• Default Gateway (e.g., 192.168.1.1): The highway on-ramp (the router). If you want to visit another town (the internet or another subnet), you MUST pass through the Default Gateway.
• RFC 1918 Private Ranges (Never routed to public internet):
- 192.168.0.0 – 192.168.255.255 (Home & small lab setups)
- 10.0.0.0 – 10.255.255.255 (Enterprises & data centers)
- 172.16.0.0 – 172.31.255.255 (Medium business/testing networks)
💬 How to say it in the interview: "When diagnosing connectivity, I first inspect ipconfig /all to confirm the host has a valid IPv4 address on the correct subnet and can reach its default gateway."

🔄 1.3 DHCP DORA Process & APIPA (169.254.x.x)
▼
🏨 Hotel Analogy: DHCP is the hotel front desk. When a guest arrives, the receptionist gives them an available room key (IP lease) with a checkout date.
The 4-Step DORA Handshake (UDP 67 Server / 68 Client):
1. Discover: Booted VM broadcasts: "Who has a DHCP server? I need an IP!"
2. Offer: DHCP server answers: "I offer 192.168.1.50 with mask 255.255.255.0."
3. Request: Client replies: "I accept the lease for 192.168.1.50!"
4. Acknowledge: Server confirms: "Leased for 8 days. Here is your DNS and Gateway."

⚠️ The Golden Interview Trap: APIPA (169.254.x.x)
If DHCP fails or the VM network adapter is disconnected, Windows automatically self-assigns an IP in the 169.254.0.1 – 169.254.255.254 range. It creates a local island: the VM cannot access other subnets or the internet.
💬 How to say it in the interview: "If a student reports no internet and their IP starts with 169.254, I know the DHCP handshake failed. I immediately check if the DHCP service is running and verify the VM's vSwitch port group."
📖 1.4 DNS & Why Active Directory Requires SRV Records
▼
📖 Phonebook Analogy: You don't memorize Google's numerical IP (142.250.190.46); you type google.com. DNS looks up the human name and returns the machine IP.
• Why Active Directory Cannot Live Without DNS:
Active Directory registers special SRV (Service) records in DNS (e.g., _ldap._tcp.dc._msdcs.corp.local). When a Windows client wants to join the domain, it asks DNS: "Where is the Domain Controller running LDAP?" DNS replies with the DC's IP.
• Top Student Lab Failure: The student's VM has its DNS set to 8.8.8.8 (Google) instead of the Domain Controller's IP. Google has no idea where corp.local is, so domain join fails.
🛠️ 1.5 7-Layer OSI Troubleshooting & Diagnostic CLI
▼
Always troubleshoot from Layer 1 upward (Bottom-Up):
• L1 Physical: Is the virtual network cable plugged in? (VMware connected checkbox).
• L2 Data Link: Is the VM on the right VLAN / vSwitch port group?
• L3 Network: Does the VM have a valid IP? Can it ping its Default Gateway?
• L4 Transport: Is the target TCP port open (e.g. 3389 for RDP, 53 for DNS)?
• L7 Application: Is the web server or Active Directory service running?

The Universal Diagnostic Sequence:
ping 127.0.0.1 # Test local TCP/IP stack ping 192.168.1.1 # Test reachability to local Gateway ping 8.8.8.8 # Test external internet routing ping google.com # Test DNS name resolution tracert 8.8.8.8 # Trace hop-by-hop packet route nslookup dc01.corp.local # Query DNS for domain controller
Stage 2 of 7 Identity & Access

🏢 Active Directory & Windows Server

In consumer tech, each PC has a separate login. In an enterprise college, Active Directory centralizes control of 1,000 users and computers.

🌳 2.1 The Hierarchy: Forests, Domains, OUs & Objects
▼
🏢 Corporate Building Analogy:
• Forest: The entire multinational corporation umbrella.
• Domain: A specific regional branch office sharing a single database (NTDS.dit).
• OU (Organizational Unit): Department filing cabinets inside the office (e.g. "Students", "Faculty", "Lab Computers"). Used to organize users and apply Group Policies.
• Objects: The individual employee files, computers, and printers inside the cabinet.
• Security vs Distribution Groups:
- Security Group: Used to assign resource permissions (e.g. "Grades-Folder-Read-Access").
- Distribution Group: Strictly for email broadcasts via Outlook/Exchange. Cannot be given permissions!
📜 2.2 Group Policy Objects (GPOs) & The LSDOU Rule
▼
What is a GPO? A centralized policy pushed by IT to hundreds of PCs at once (e.g. disable USB drives, enforce 12-character passwords, set desktop wallpaper).

LSDOU Processing Order:
1. Local machine policy
2. Site policy
3. Domain root policy
4. OU policy (child OUs apply after parent OUs)
The Rule: Settings applied later in the hierarchy overwrite earlier conflicting settings.
Exceptions:
• Enforced: A GPO set to Enforced at the Domain level cannot be overridden by any child OU.
• Block Inheritance: An OU can block policies flowing down from parent levels.

Essential Diagnostic Commands:
gpupdate /force # Force machine to immediately apply new GPOs gpresult /r # Display summary of applied policies for user & computer gpresult /h gpo.html# Generate detailed HTML diagnostic report
👑 2.3 The 5 FSMO Roles (Explained Simply)
▼
Active Directory allows multiple Domain Controllers to replicate changes, but 5 critical jobs can only be handled by a single DC at any moment:

Forest-Wide (Only 1 in the entire organization):
1. Schema Master: Dictates the structural blueprint of AD (what fields exist for a user).
2. Domain Naming Master: Authorizes adding or removing domains from the forest.

Domain-Wide (1 per domain):
3. PDC Emulator (Most Critical): Master time source (NTP), processes password changes immediately, handles account lockouts.
4. RID Master: Issues pools of Relative IDs so every new user/computer gets a unique SID.
5. Infrastructure Master: Updates cross-domain object references.
💬 How to say it in the interview: "If users experience login failures after a password reset, or client clocks drift, I immediately investigate the health of the PDC Emulator FSMO role."
💻 2.4 Domain Join & Essential PowerShell for AD
▼
How a Computer Joins a Domain:
1. Admin types domain name (e.g. corp.local) in System Properties.
2. Client queries DNS for _ldap._tcp.dc._msdcs.corp.local.
3. DNS returns the Domain Controller's IP.
4. Client contacts DC on Port 88 (Kerberos) and prompts for Domain Admin credentials.
5. Computer account is created in AD; machine reboots.

Essential PowerShell Cmdlets for Sysadmins:
Get-ADUser -Identity "jdoe" -Properties * # View all attributes Unlock-ADAccount -Identity "jdoe" # Unlock locked account Set-ADAccountPassword "jdoe" -Reset # Reset user password New-ADUser -Name "Jane Smith" -SamAccountName "jsmith" -Enabled $true
Stage 3 of 7 Virtualization

🖥️ VMware vSphere & Hypervisors

Colleges never let students practice on physical servers. Every student lab runs inside virtual machines.

⚙️ 3.1 Type 1 (ESXi) vs Type 2 Hypervisors
▼
🏢 Real-World Analogy:
• Type 1 (Bare-Metal): An apartment building built directly on the foundation. High-efficiency, enterprise grade.
• Type 2 (Hosted): Tents pitched on top of an apartment floor. Easy to set up for personal use, but has extra overhead.
• Type 1 (Bare-Metal): Installed directly on physical server hardware without any Windows/Linux OS underneath (e.g. VMware ESXi, Microsoft Hyper-V). Enterprise standard.
• Type 2 (Hosted): Installed as an application inside Windows/macOS (e.g. VMware Workstation Pro, VirtualBox). Used for desktop testing.
• vCenter Server: Central management console for managing clusters of ESXi hosts, enabling vMotion (live migration) and High Availability (HA).
📸 3.2 Snapshots vs Backups (The #1 Interview Trap)
▼
How a Snapshot Works:
When you take a snapshot, VMware freezes the original virtual hard disk (.vmdk) as read-only. All new writes are redirected to a delta file (-delta.vmdk). Clicking "Revert" simply throws away the delta file.

⚠️ Why Snapshots are NOT Backups:
1. Dependency: If the base disk corrupts or is deleted, all snapshots are completely useless.
2. Storage Exhaustion: Delta files grow continuously, increasing disk read latency and filling up datastores.
3. Lab Tester Use: We use snapshots strictly to revert VMs to a clean baseline before and after testing exercises.
💬 How to say it in the interview: "I always emphasize to students that snapshots are short-term rollbacks for lab exercises, never permanent backups, because delta chains degrade datastore I/O performance."
🌐 3.3 Virtual Networking (vSwitch) & VMware Tools
▼
• Standard Switch (VSS): Virtual switch configured on an individual ESXi host.
• Distributed Switch (VDS): Unified virtual switch spanning an entire cluster of hosts in vCenter.
• Port Groups: Logical network connections on a switch (e.g., "Student-Lab-Net", "VLAN-20").
• VMware Tools: Essential driver suite inside guest OS providing:
- VMXNET3 virtual network driver for 10 Gbps speeds.
- Smooth mouse movement without ungrabbing keyboard.
- Time sync with ESXi host clock.
- Graceful guest OS shutdown.
Stage 4 of 7 Cloud Core

☁️ Microsoft Azure & Microsoft 365

Modern colleges operate in a hybrid cloud model, combining on-premises Active Directory with Azure and Microsoft 365.

☁️ 4.1 Cloud Service Models: IaaS, PaaS, SaaS
▼
🍕 The Pizza Analogy:
• On-Premises: Making pizza at home from scratch (you buy the oven, cheese, dough, clean dishes).
• IaaS (Infrastructure as a Service): Take and bake (store gives you the pizza, you bake it in your oven). You manage the OS, software, and patches. E.g., Azure Virtual Machines, VNets.
• PaaS (Platform as a Service): Pizza delivery (pizza arrives ready, you just supply the table and drinks). Provider manages OS and scaling; you just upload code/data. E.g., Azure App Services, Azure SQL.
• SaaS (Software as a Service): Eating at a restaurant (you just sit and eat). Everything is managed for you. E.g., Microsoft 365, Teams, Outlook.
🆔 4.2 Microsoft Entra ID (Azure AD) vs On-Premises AD
▼
• On-Premises AD: Hierarchical (Forest/Domain/OU), Kerberos/NTLM authentication, LDAP queries, GPOs, requires Windows Server Domain Controllers.
• Microsoft Entra ID: Flat directory (Users & Groups), web protocols (OAuth 2.0, OpenID Connect, SAML), REST API (Microsoft Graph), governed by Conditional Access policies and MFA.
• Hybrid Identity: Microsoft Entra Connect syncs on-premises users and password hashes to the cloud for Single Sign-On (SSO).
🛡️ 4.3 Azure VNets, NSGs & M365 Shared Mailboxes
▼
• Azure NSG (Network Security Group): Virtual firewall that controls inbound/outbound traffic based on 5 parameters (Source, Source Port, Destination, Destination Port, Protocol).
• NSG Priority Rule: Rules range from 100 to 4096. Lower numbers have higher priority! Rule 100 is evaluated before Rule 200.

• Exchange Online Shared Mailboxes (e.g. support@college.ca):
- Free of charge: Does NOT require a paid user license if mailbox is under 50 GB!
- Send As: Recipient sees email came directly from support@college.ca.
- Send on Behalf: Recipient sees User on behalf of support@college.ca.
Stage 5 of 7 Partner Tech

🐧 Red Hat Linux, Cisco & Citrix

The college is partnered with Citrix, Cisco, and Red Hat. Having these fundamentals protects you from any curveball question.

🐧 5.1 Red Hat Enterprise Linux (RHEL) & Permissions
▼
• Directory Hierarchy:
- /etc: System configuration files (network scripts, service configs).
- /var/log: System log files (check /var/log/messages when errors occur).
- /var/www/html: Web server root directory.

• Permissions Math (Read=4, Write=2, Execute=1):
- chmod 755 script.sh: Owner has 7 (rwx), Group has 5 (r-x), Others have 5 (r-x). Standard for scripts and web folders.
- chmod 644 config.txt: Owner has 6 (rw-), Group/Others have 4 (r--). Standard for files.
- chown -R apache:apache /var/www/html: Recursively change owner and group.

• Managing Services (systemd):
systemctl status httpd # Check if service is active systemctl restart httpd # Restart service after editing configs journalctl -u httpd -xe # View detailed failure crash logs
🔀 5.2 Cisco Switching: Access vs Trunk Ports
▼
• VLAN (Virtual LAN): Breaks up physical switches into separate broadcast domains.
• Access Port: Belongs to a single VLAN; connects end devices (PCs, printers). Traffic is untagged.
• Trunk Port: Connects switch-to-switch or switch-to-router; carries traffic for multiple VLANs using IEEE 802.1Q encapsulation tags.
• Inter-VLAN Routing: Machines in different VLANs cannot talk at Layer 2; traffic must be forwarded by a Layer 3 router or Layer 3 switch.
🖥️ 5.3 Citrix Virtual Apps & Desktops (VDI)
▼
Citrix enables remote students to stream pre-configured Windows/Linux lab machines directly inside a web browser.
• Citrix StoreFront: The web authentication portal where students log in.
• VDA (Virtual Delivery Agent): Agent installed on the lab VM that streams the desktop session over the HDX / ICA protocol.
• Common Student Issue: Session freezes due to high network packet loss or VDA displays "Unregistered" in the management console.

Identity & Access Top Priority

1. Microsoft Active Directory (AD DS)

📂 Structure: Forest, Domain, OU & Objects
▼
• Forest: The highest logical security boundary. Contains one or more domain trees that share a common schema, global catalog, and directory configuration.
• Domain: Administrative boundary storing objects (users, computers, groups) in the database NTDS.dit.
• Organizational Unit (OU): Sub-containers inside a domain used to organize objects logically and link Group Policy Objects (GPOs). OUs are not security principals.
• Security vs Distribution Groups: Security groups assign permissions to resources (file shares, printers); Distribution groups are strictly for email broadcast lists (Exchange).
📜 Group Policy Objects (GPOs) & LSDOU Order
▼
• Processing Hierarchy (LSDOU):
1. Local: Local policy on machine.
2. Site: AD physical site.
3. Domain: Root domain policy.
4. OU: Nested OUs from parent to child.
Rule: Latest applied setting wins, unless a parent has "Enforced" (overrides everything) or an OU has "Block Inheritance".
• Crucial Diagnostic Commands:
gpupdate /force # Force immediate GPO refresh gpresult /r # Show applied computer & user GPOs gpresult /h gpo.html # Export detailed HTML diagnostic report
👑 The 5 FSMO Roles (Forest vs Domain Wide)
▼
Forest-Wide Roles (Only 1 per Forest):
1. Schema Master: Controls additions and edits to the AD schema classes/attributes.
2. Domain Naming Master: Controls adding or removing domains/partitions from the forest.

Domain-Wide Roles (1 per Domain):
3. PDC Emulator: Authoritative time source (NTP), processes password changes immediately, handles account lockouts.
4. RID Master: Allocates pools of Relative IDs to Domain Controllers for creating unique SIDs.
5. Infrastructure Master: Updates cross-domain object references and GUIDs.
🔧 Common Student AD Lab Roadblocks
▼
• "Cannot join domain: Network path not found": The client VM is using 8.8.8.8 or router IP for DNS instead of the Domain Controller static IP.
• GPO not applying: The computer object was left in the default CN=Computers container instead of being moved into the targeted OU where the GPO is linked.
• Account Lockout: User exceeded bad password threshold. Fix via Unlock-ADAccount -Identity username in PowerShell.

🖥️ Type 1 vs Type 2 Hypervisors
▼
• Type 1 (Bare-Metal): Installed directly on physical server hardware without an underlying OS (e.g., VMware ESXi, Microsoft Hyper-V, Proxmox VE). High performance, enterprise standard.

• VMware Tools: Essential driver suite providing optimized video, mouse sync, VMXNET3 virtual NIC drivers, and guest OS heartbeat.
Partner: Cisco Core Pillar

3. Networking & Cisco Lab Foundations

🪜 OSI Model (7 Layers) vs TCP/IP Troubleshooting
▼
1. Physical (L1): Cables, NIC link lights, SFP transceivers.
2. Data Link (L2): MAC addresses, switches, VLANs, frames.
3. Network (L3): IP addresses, routers, packets, ICMP.
4. Transport (L4): TCP (reliable, 3-way handshake SYN-SYNACK-ACK) vs UDP (connectionless).
5. Session (L5): Session establishment and termination.
6. Presentation (L6): Formatting, SSL/TLS encryption, compression.
7. Application (L7): DNS, DHCP, HTTP/HTTPS, SSH, RDP.
Troubleshooting Principle: Always diagnose bottom-up: Check VM network cable connected → Check IP/DHCP lease → Check default gateway ping → Check DNS resolution.
🔄 DHCP DORA & APIPA (169.254.x.x)
▼
DORA Process (UDP 67 Server / 68 Client):
• Discover: Client broadcasts to 255.255.255.255.
• Offer: DHCP server offers an unassigned IP.
• Request: Client requests the offered IP.
• Acknowledge: Server confirms and binds the lease.
APIPA (Automatic Private IP Addressing):
If no DHCP server responds, Windows self-assigns an IP in the 169.254.0.1 to 169.254.255.254 range with subnet mask 255.255.0.0. It allows local link communication but cannot route to other subnets or the internet.
🔀 Cisco Switching: VLANs, Trunks & Access Ports
▼
• VLAN (Virtual LAN): Breaks up broadcast domains on Layer 2 switches. Devices in different VLANs cannot communicate without a Layer 3 router (Router-on-a-Stick or L3 switch).
• Access Port: Belongs to a single VLAN; carries untagged traffic to end devices (PCs, servers).
• Trunk Port: Carries traffic for multiple VLANs between switches using the IEEE 802.1Q tagging standard.
• Default Gateway: The router interface IP on the local subnet that forwards packets destined for remote networks.

4. Microsoft Azure & Cloud Architecture

☁️ Cloud Service Models: IaaS, PaaS, SaaS
▼
• IaaS (Infrastructure as a Service): Azure Virtual Machines, VNets, Managed Disks. You manage OS, patches, middleware, and applications. Microsoft manages physical hardware and hypervisors.

🆔 Microsoft Entra ID vs On-Prem Active Directory
▼
• On-Premises AD: Hierarchical (Forest/Domain/OU), Kerberos & NTLM authentication, LDAP directory queries, managed via Group Policy (GPO).
• Microsoft Entra ID (Azure AD): Flat cloud identity service, web protocols (OAuth 2.0, OpenID Connect, SAML), REST API queries (Microsoft Graph), secured via Conditional Access & MFA.
• Entra Connect: Synchronizes on-premises user hashes to Entra ID for hybrid single sign-on (SSO).
🛡️ Azure Virtual Networks & NSGs (Network Security Groups)
▼
• VNet (Virtual Network): Isolated virtual network in Azure divided into subnets.
• NSG (Network Security Group): Virtual firewall filtering inbound and outbound traffic based on 5-tuple: Source, Source Port, Destination, Destination Port, Protocol.
• Common Lab Issue: Student cannot RDP (port 3389) or HTTP (port 80) into an Azure VM because the inbound NSG rule was either omitted or configured with wrong priority.

📬 Exchange Online & Shared Mailboxes
▼
• Shared Mailbox: Allows a team to monitor and send email from a common address (e.g., support@college.ca). Does NOT require a paid license if storage is under 50 GB!
• Delegation Permissions:
- Send As: Recipient sees the email came directly from the mailbox.
- Send on Behalf: Recipient sees "User on behalf of Support".
- Read and Manage (Full Access): Allows opening the mailbox in Outlook.
🔐 Multi-Factor Authentication (MFA) & Security Defaults
▼
• Security Defaults: Microsoft-managed basic security settings that require all users to register for MFA using the Microsoft Authenticator app and block legacy authentication.
• Conditional Access: Enterprise feature (Entra ID P1/P2) allowing granular if-then policies (e.g., "Require MFA if user logs in from outside Canada").
